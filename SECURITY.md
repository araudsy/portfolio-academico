# Política de Segurança

## Escopo
Este repositório (PortfolioHUB) é um portfólio acadêmico público. Não armazena dados de terceiros, senhas ou chaves de acesso.

## Medidas adotadas
- **Autenticação em duas etapas (2FA)** ativa na conta do proprietário.
- **Controle de acesso:** colaboradores com permissão de escrita, concedida apenas mediante convite.
- **Proteção da branch `main`:** alterações somente por pull request com revisão.
- **Prevenção de vazamentos:** `.gitignore` configurado, Secret Protection (secret scanning) e Push Protection ativos, que bloqueiam o envio de segredos como tokens e senhas.
- **Dependências:** Dependency graph, Dependabot alerts e Dependabot security updates ativos.
- **Relato de vulnerabilidades:** Private vulnerability reporting ativo.
- **Privacidade (LGPD):** nenhum dado pessoal de terceiros é publicado; dados pessoais próprios restringem-se ao que consta no perfil profissional.

## Como reportar uma vulnerabilidade
Use a aba **Security > Report a vulnerability** deste repositório para enviar o relato de forma privada. Não abra issues públicas para falhas de segurança.

## Resposta
Relatos serão analisados em até 7 dias.
