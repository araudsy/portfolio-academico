# Guia de Contribuição

Obrigado por colaborar com o PortfolioHUB! Siga este fluxo para propor alterações.

## Fluxo de trabalho
1. Abra uma **issue** descrevendo a alteração, bug ou ideia.
2. Crie um **branch** a partir da `main`, com nome descritivo (`feat/nome`, `fix/nome` ou `docs/nome`).
3. Faça **commits** pequenos e claros.
4. Abra um **pull request** referenciando a issue (`Closes #número`).
5. Aguarde a **revisão e aprovação** do proprietário antes do merge.

## Convenção de commits
- `feat:` nova funcionalidade ou conteúdo
- `fix:` correção de erro
- `docs:` alteração em documentação

Exemplo: `docs: atualiza README com novo projeto`

## Regras
- A branch `main` é protegida: não há envio direto, somente via pull request aprovado.
- Não inclua senhas, tokens, documentos ou dados pessoais de terceiros.
- Mantenha mensagens e documentação em português, com respeito e clareza.
