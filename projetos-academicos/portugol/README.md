# Exercícios de Portugol

Exercícios de lógica de programação feitos em sala, na disciplina de Lógica de Programação.

## Tecnologias
- Portugol (Portugol Webstudio)

## Conteúdo
- Arquivos `.por` com as resoluções das listas de exercícios.

## Como executar
1. Acesse o Portugol Webstudio (dgadelha.github.io/Portugol-Webstudio).
2. Abra o arquivo `.por` desejado pelo menu de arquivos.
3. Clique em executar.

## O que aprendi
- Estruturas de repetição;
- Estruturas condicionais.
