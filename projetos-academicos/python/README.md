# Exercícios de Python

Exercícios das aulas 01 a 15 do curso de Python, desenvolvidos para praticar os fundamentos da linguagem.

## Tecnologias
- Python 3

## Conteúdo
- `aula01.py` a `aula15.py`: um arquivo por aula, com os exercícios resolvidos.

## Como executar
1. Instale o Python 3 (python.org).
2. Baixe ou clone o repositório.
3. Na pasta do projeto, rode: `python aula01.py` (troque pelo arquivo desejado).

## O que aprendi
- Comandos simples;
- Tipos primitivos;
- int, float, bool, str;
- Operações aritméticas;
- Ordem de precadência;
- Módulos em Python;
